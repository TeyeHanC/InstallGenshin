# InstallGenshin

打开容易分心的程序时，给自己一个意想不到的提醒。默认规则是：**打开《无畏契约》 → 打开原神官方下载页**。你也可以选择其他触发程序和提醒网页。

> InstallGenshin 目前只会打开网页，**不会下载或安装原神**，也不会阻止触发程序运行。

**[体验在线交互预览](https://raw.githack.com/TeyeHanC/InstallGenshin/main/docs/index.html)** · 预览通过第三方静态文件镜像提供，更新可能延迟几分钟。它只展示界面和模拟操作；检测电脑上运行的程序需要使用下面的 Windows 本地版。

## Windows 本地版：从下载到第一次触发

需要 Windows 10 或 11；使用系统自带的 Windows PowerShell 5.1，不必安装 Node.js 或其他依赖。

1. 在本仓库页面点击绿色 **Code** 按钮，选择 **Download ZIP**。下载后先**全部解压**，不要在压缩包预览窗口里直接运行文件。
2. 打开解压后的文件夹，双击 **`Start-InstallGenshin.cmd`**。它会启动一个命令窗口，并在默认浏览器打开控制台。若浏览器没有自动打开，手动访问 `http://127.0.0.1:38127/`。
3. 在“当我打开…”中保留 **无畏契约**预设，或点击“选择运行中的应用”。也可以直接输入进程文件名，例如 `VALORANT-Win64-Shipping.exe`。
4. 在“就提醒我…”中选择 **打开原神官方下载页**，或填写你自己的 `https://` 网页地址。
5. 打开“启用这条规则”开关，选择冷却时间，然后点击 **保存并开始守护**。
6. 现在启动触发程序。当它从未运行变为运行时，InstallGenshin 会在默认浏览器打开提醒网页。控制台的“最近的轨迹”会显示触发记录。

**保持命令窗口运行。** 关闭它就会停止检测；只关浏览器标签页不会停止后台检测。重新打开本地地址即可继续调整设置。

## 按钮与触发规则

| 控件 | 用途 |
| --- | --- |
| 选择运行中的应用 | 列出当前进程，点击后把 `.exe` 文件名填入触发框。目标程序不在列表时，可以手动输入。 |
| 自定义网页 | 输入完整的 `https://` 地址，作为触发后的提醒页。 |
| 启用这条规则 | 控制是否实际检测进程。切换后需要点击保存。 |
| 冷却时间 | 限制两次触发之间的最短间隔，默认 30 分钟。 |
| 测试已保存的触发动作 | 立即打开**上次保存**的提醒网页，不需要先打开触发程序；测试不会消耗冷却时间。 |

同一次程序运行只触发一次。关闭触发程序后再打开，才会形成下一次“启动”事件；若仍在冷却时间内，这次事件不会打开网页。启动 InstallGenshin 时，如果目标程序已经在运行，也可能触发一次提醒。

## 常见问题

**打开游戏后没有反应？** 确认命令窗口仍在运行、开关已经开启并保存、冷却时间已经结束。再到 Windows“任务管理器 → 详细信息”查看真正的进程文件名；游戏启动器和游戏本体可能有不同名称。

**浏览器没有自动打开控制台？** 手动访问 `http://127.0.0.1:38127/`。如果命令窗口提示端口被占用，先关闭之前运行的 InstallGenshin，再重新启动。

**如何退出或清除设置？** 关闭命令窗口即退出。设置和最近 30 条记录保存在 `%APPDATA%\InstallGenshin\`；退出后可删除该文件夹来重置。

本地控制台只监听你电脑的 `127.0.0.1`。规则和记录保存在本机；打开的提醒网页会按该网站自身的方式联网。

## 在线预览与本地版的区别

在线预览是静态演示页，设置保存在预览浏览器的本地存储中；“模拟一次触发”只添加演示记录。它不会读取电脑进程，也不会替代 Windows 本地版。
